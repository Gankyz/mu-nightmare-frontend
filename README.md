# MU Nightmare — Front-end (Home)

Front-end da página inicial do servidor MU Nightmare (HTML, CSS e JS puros).

- `index.html` — página inicial
- `shared/` — estilos globais, navbar, layout (header/footer), textos (`i18n/`) e notícias (`news.js`)
- `pages/home/` — CSS e JS da home
- `images/` — logo, ícones, fundo e imagens das notícias (`images/news/`, proporção 16:10)

Para publicar uma notícia, adicione um item no topo de `shared/news.js` com textos em `en` e `pt`.
